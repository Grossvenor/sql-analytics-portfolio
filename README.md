# SQL Analytics Portfolio

Портфель SQL-запросов для позиции **Junior SQL / Data Analyst**.

Здесь собраны практические задачи по аналитике данных, которые отражают мой уровень владения SQL и понимание бизнес-метрик.

---

 Используемые технологии

- PostgreSQL
- SQL (JOIN, CTE, подзапросы, оконные функции)
- Агрегации и метрики
- Работа с датами
- Аналитические функции (LAG, RANK, DENSE_RANK)

---

Что представлено в репозитории

 Аналитика заказов и выручки
- расчёт дневной выручки
- исключение отменённых заказов
- кумулятивные метрики

 Оконные функции
- накопительные показатели
- LAG / LEAD
- скользящие средние
- ранжирование пользователей

 Пользовательская аналитика
- количество заказов
- доля отмен
- динамика действий пользователя

Каждый кейс оформлен в отдельной папке и сопровождается SQL-файлами с комментариями.

---

 Цель репозитория

- продемонстрировать практические навыки SQL
- показать понимание аналитических задач
- подготовиться к работе на позиции Junior Analyst
