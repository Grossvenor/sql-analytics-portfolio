
 Описание кейса

Кейс направлен на анализ частоты заказов пользователей.
Основная задача — определить, сколько времени проходит между заказами одного пользователя.

---
 Задача

Для каждого заказа пользователя:
- определить предыдущий заказ
- рассчитать временной интервал между заказами
- сохранить корректный уровень агрегации (1 строка = 1 заказ)

---
 Логика решения

Уровень агрегации
Анализ ведётся на уровне отдельных заказов, без использования агрегирующих функций.

Оконные функции
Используется функция `LAG()` для получения времени предыдущего заказа пользователя.

Окно определяется:
- `PARTITION BY user_id`
- `ORDER BY order_time`

 Обработка первого заказа
Для первого заказа пользователя предыдущего значения не существует, поэтому `LAG()` возвращает `NULL`.
Это поведение сохраняется намеренно, без замены на 0.



 Используемые SQL-инструменты

- `LAG()`
- `PARTITION BY`
- `ORDER BY`
- работа с временными интервалами
- `EXTRACT(EPOCH FROM interval)`
