Кейс 1 — Дневная выручка и её динамика

 Описание задачи

На основе таблиц `orders`, `products`, `user_actions`:

- рассчитана дневная выручка сервиса
- исключены отменённые заказы
- посчитана кумулятивная выручка
- рассчитан дневной прирост выручки с помощью `LAG()`

---

 Используемые таблицы

- `orders` — заказы и товары в заказе
- `products` — цены товаров
- `user_actions` — действия пользователей (включая отмены)

---

 Используемые навыки

- JOIN
- UNNEST массивов
- GROUP BY
- оконные функции (`SUM() OVER`, `LAG()`)
- работа с датами (`creation_time::date`)
- обработка NULL (`COALESCE`, `CASE`)

---

 Файлы

- `daily_revenue.sql` — основной SQL-запрос с комментариями

 Результат

Получена таблица с метриками:
